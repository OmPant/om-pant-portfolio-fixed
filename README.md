# Om Pant — Developer Portfolio

A personal portfolio website showcasing my projects, technical interests, and learning journey as a student and aspiring developer.

## ✨ Overview

This portfolio features a modern, dark-themed design with purple, pink, and cyan accents. It highlights my work in web development, programming, game development experiments, and personal AI projects.

The website is built using HTML5 and CSS3, with a focus on responsive layouts, visual details, and accessible design.

## 🚀 Features

- Modern dark-themed interface
- Responsive layout for desktop, tablet, and mobile
- Personal introduction and about section
- Technical skills and tools overview
- Selected projects with repository links
- Professional office portrait in the hero section
- Smooth scrolling and CSS animations
- Hover effects and gradient accents
- Contact section and GitHub links
- Reduced-motion accessibility support

## 🛠️ Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, animations, and transitions
- **Flexbox** — Flexible layouts and alignment
- **CSS Grid** — Responsive page layouts
- **Media Queries** — Responsive design
- **Git & GitHub** — Version control and hosting

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/OmPant/om-pant-portfolio-fixed.git
   ```

2. Open the project folder:

   ```bash
   cd om-pant-portfolio-fixed
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
